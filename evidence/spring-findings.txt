Spring.FixedUpdate explicit metadata parameter 'frame' typeIndex23125 (Frame typeDef3508); use void(self,Frame*,MethodInfo*) Windows x64. The current generated body ignores Frame and MethodInfo, but hooks should preserve all arguments. CalcCurrDist has zero explicit parameters, returns Single: float(self,MethodInfo*).
For xDrive injected icalls, use void(ArticulationBody* managed_wrapper, ArticulationDrive* value). Exact CreateJoint instruction sequence loads this+0x60 straight into rcx and calls cached getter/setter; there is NO +0x10 cached-native-pointer dereference at this call site. Therefore do not pass the native component pointer from managed_wrapper+0x10. No MethodInfo passed to the injected native functions.
Part id confirmed definition ID by PartSO.Find disassembly: signed ID indexes global byId array at +0x20+id*8; thus id is not a vehicle instance serial number.
Drive fields are seven contiguous floats followed by int driveType. Both getter and setter copy two full 16-byte chunks =32bytes. Preserve lower/upper limits,target,targetVelocity,driveType. Stock forceLimit is exactly original stiffness. Raising stiffness while retaining stock force limit saturates force; matching forceLimit to tuned stiffness preserves stock coupling. But setting stiffness=0 and forceLimit=0 also disables all damping force, so independent damping at zero stiffness requires keeping a positive force limit. Expose/document a force-limit choice or preserve original cap for zero-stiffness use.
